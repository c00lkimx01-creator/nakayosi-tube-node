第3章 二次関数

本章では二次関数 y = ax² + bx + c の性質、平方完成、頂点座標、最大値・最小値について学習する。

3.1 平方完成

y = ax² + bx + c を y = a(x − p)² + q の形に変形することを平方完成という。
p = −b / (2a) , q = c − b² / (4a)

3.2 グラフの頂点

頂点は (p, q)。a > 0 のとき下に凸、a < 0 のとき上に凸。

3.3 演習

  1. y = x² − 4x + 7 を平方完成せよ。
  2. y = −2x² + 8x − 3 の最大値を求めよ。
  3. y = x² + 2ax + 1 が x 軸と接するときの a を求めよ。
